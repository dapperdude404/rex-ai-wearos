# Rex AI — Wear OS

An independent AI companion for Samsung Galaxy Watch 6, developed by dapperdude404.

Package: `com.dapperdude404.rexai`

## Roadmap
- Native Kotlin and Compose for Wear OS
- Animated dinosaur companion
- Voice input and spoken replies in English, Hindi and Hinglish
- Secure backend for AI requests; never embed API keys in the APK
- Local conversation history and battery-aware operation
- Automated debug APK builds and physical watch testing

## Status
Planning and initial repository setup. No working APK or tested AI integration yet.
